## Not implemented (stated honestly)

| Item | Reason |
|---|---|
| Content-Security-Policy header | needs per-request nonces; listed as a next step in docs 44 and 47 |
| JSON-LD structured data | no public entity worth marking up |
| Shared (multi-instance) cache handler and refresh lock | single-instance deployment assumed; caveats in `docs/deployment.md` |
| Employee date-range filter | the backend's `GET /employees` has no date filter (see `docs/backend-api-integration.md`); date ranges exist on attendance, leave, reports |
| Education / experience / skills / certifications persistence | no backend endpoint; stored in the browser with a visible banner |
| WebSocket notifications | backend has none; polling is used |
| Asserting HTTP 404 *status* for a late `notFound()` | Cache Components streams the shell first (see rendering doc) — the e2e checks the not-found marker + `noindex` instead |
