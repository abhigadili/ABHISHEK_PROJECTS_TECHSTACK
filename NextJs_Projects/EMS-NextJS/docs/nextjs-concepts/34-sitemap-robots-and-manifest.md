# 34. Sitemap, robots and manifest

> **Version:** Next.js 16.4.5 · React 19.3.0 · TypeScript 5.9 (App Router, `cacheComponents` enabled). Examples use the App Router only (no Pages Router APIs). Deprecated or removed APIs are called out where relevant.

## 1. Concept explanation
Special route files generate `/sitemap.xml`, `/robots.txt` and `/manifest.webmanifest` from TypeScript.

## 2. Syntax
```ts
export default function sitemap(): MetadataRoute.Sitemap { return [{ url, lastModified, changeFrequency, priority }]; }
export default function robots(): MetadataRoute.Robots { return { rules: [{ userAgent: '*', allow: […], disallow: […] }], sitemap }; }
export default function manifest(): MetadataRoute.Manifest { return { name, short_name, start_url: '/dashboard', display: 'standalone', … }; }
```

## 3. How Next.js implements it
These files are statically generated by default. `icon.tsx` / `apple-icon.tsx` use `ImageResponse` to generate PNGs at build time.

## 4. Actual EMS implementation
* `sitemap.ts` lists only **public** pages, built from the same `DOCS`/`HELP` arrays that generate the pages (so it cannot drift).
* `robots.ts` allows `/`, `/help`, `/docs`; disallows `/api/`, every authenticated area, the auth pages and `/learn`; points at the sitemap.
* `manifest.ts` makes EMS installable (`start_url: '/dashboard'`, standalone, theme colours).
* `icon.tsx`, `apple-icon.tsx`: generated icons (also `public/icons`).

## 5. Relevant file paths
- `src/app/sitemap.ts`
- `src/app/robots.ts`
- `src/app/manifest.ts`
- `src/app/icon.tsx`
- `src/app/apple-icon.tsx`
- `tests/seo.test.ts`

## 6. Practical use case
A crawler fetches `/robots.txt`, sees the disallow list, reads `/sitemap.xml` and indexes only help/docs.

## 7. Why the concept is used
Controlled crawling and installability.

## 8. Advantages
- Typed, generated from the same content source.

## 9. Limitations
- `lastModified` here is a fixed date (no per-article timestamps in the content source).
- robots.txt is advisory — authentication is the real protection.

## 10. Common mistakes
- Listing private URLs in the sitemap.
- Expecting robots.txt to hide pages from users.
