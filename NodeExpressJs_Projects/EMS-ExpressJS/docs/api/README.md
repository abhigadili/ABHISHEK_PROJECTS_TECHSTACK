# API documentation

* `openapi.json` — generated OpenAPI 3.0 document (`npm run docs:openapi`).
* Live Swagger UI: `http://localhost:4100/api-docs`; live spec: `/api-docs/openapi.json`.
* The spec is built from the endpoint table in `src/docs/openapi.js` (single source of truth), including per-endpoint roles, parameters and request bodies.
