## PHASE 5 — TypeScript Verification

```bash
# First check — found 3 categories of errors
npx tsc --noEmit
```

### Errors Found & Fixed

**Error 1: Express `req.user` type conflict**

Passport declares `req.user` as `Express.User`. Our `AuthRequest` extended `Request` with a custom `user?: JwtPayload` — mismatch.

*Fix:* Created `src/types/express.d.ts` to augment the Express namespace:
```typescript
declare global {
  namespace Express {
    interface User extends JwtPayload {}
    interface Request { requestId?: string; }
  }
}
```
Changed `AuthRequest` from an interface to `type AuthRequest = Request`.

---

**Error 2: `preserveNullAndEmpty` typo in aggregation**

In `src/controllers/mongodb.controller.ts` — wrong property name on `$unwind` stage.

*Fix:*
```typescript
// Before (wrong)
{ $unwind: { path: '$department', preserveNullAndEmpty: false } }

// After (correct)
{ $unwind: { path: '$department', preserveNullAndEmptyArrays: false } }
```

---

**Error 3: `jwt.sign()` expiresIn type**

`jsonwebtoken` v9 expects `StringValue` for `expiresIn`, not plain `string`.

*Fix:* Cast to `any`:
```typescript
jwt.sign(payload, secret, { expiresIn: config.jwt.expiresIn as any })
```

---

**Error 4: `sendCreated` calling `sendSuccess` with status 201**

`sendSuccess` was typed to only accept `200`. Inlined the implementation for `sendCreated`.

---

**Error 5: `tsconfig.json` rootDir conflict**

`rootDir: ./src` excluded `scripts/seed.ts` which was in `include`.

*Fix:* Changed `"rootDir": "./src"` → `"rootDir": "."`.

---

**Error 6: Route handler type mismatches**

Controllers typed as `AuthRequest` handlers couldn't be assigned directly to Express router slots.

*Fix:* Cast all route handlers with `as RequestHandler` in route files:
```typescript
router.use(authenticate as RequestHandler);
router.get('/', companyController.getAll as RequestHandler);
```

## PHASE 7 — How to Run (After Creation)

```bash
cd ~/Documents/NodeOrExpressJS_Projects/lm-company-portal

# 1. Copy environment file and configure
cp .env.example .env
# Edit .env: set MONGO_URI, REDIS_HOST, JWT_SECRET, etc.

# 2. Seed the database (requires MongoDB running on 27017)
npm run seed

# 3. Start in development mode (hot reload via ts-node-dev)
npm run dev

# 4. Build for production
npm run build   # outputs to dist/

# 5. Run production build
npm start

# 6. Run all tests
npm test

# 7. Run tests with coverage report
npm run test:coverage
```
