# Event DTO examples

All events are immutable Java `record`s in `common-library/src/main/java/com/hrportal/common/events/HrEvents.java`, implementing the marker `HrEvent` and carrying an `EventMetadata` envelope.

```java
public record EventMetadata(String eventId, String eventType, int version, Instant timestamp,
                            String correlationId, String sourceService) { ... }

public record LeaveApproved(EventMetadata metadata, String employeeId, String applicationId, String leaveType,
                            LocalDate fromDate, LocalDate toDate, BigDecimal days, String decidedBy,
                            String comment) implements HrEvent { }

public record PayrollProcessed(EventMetadata metadata, String employeeId, String runId, String month,
                               int employeeCount, BigDecimal totalGross, BigDecimal totalNet,
                               List<PayrollLine> lines) implements HrEvent { }

public record NotificationRequested(EventMetadata metadata, String employeeId, String recipientEmail, String type,
                                    String templateCode, Map<String,String> params, List<String> channels,
                                    String referenceType, String referenceId, String dedupKey) implements HrEvent { }
```

| Field | Meaning |
|---|---|
| `eventId` | UUID, the idempotency key (`processed_events` ledger) |
| `eventType` | the topic name |
| `version` | schema version (1) - consumers ignore unknown fields so additive changes are safe |
| `timestamp` | UTC instant of creation |
| `correlationId` | copied from the request's MDC, so one user action can be followed across services in the logs |
| `sourceService` | `spring.application.name` of the producer |

Serialisation: Jackson with `JavaTimeModule`, dates as ISO strings (`WRITE_DATES_AS_TIMESTAMPS` off); the Kafka value is a plain JSON string (`StringSerializer`), so consumers deserialize with their own `ObjectMapper` (tolerant of unknown properties).

## All DTOs

| Topic | Record | Payload fields (besides `metadata`) |
|---|---|---|
| employee.created | `EmployeeCreated` | employeeId, employeeCode, firstName, lastName, workEmail, departmentId, designationId, locationId, managerId, jobGradeId, joiningDate, status |
| employee.updated | `EmployeeUpdated` | employeeId, employeeCode, fullName, workEmail, departmentId, designationId, locationId, managerId, status, changedFields |
| employee.terminated | `EmployeeTerminated` | employeeId, employeeCode, status, reason, effectiveDate |
| leave.applied | `LeaveApplied` | employeeId, applicationId, leaveType, fromDate, toDate, days, managerId, reason |
| leave.approved / rejected / cancelled | `LeaveApproved` / `LeaveRejected` / `LeaveCancelled` | employeeId, applicationId, leaveType, fromDate, toDate, days, decidedBy, comment |
| attendance.checked-in | `AttendanceCheckedIn` | employeeId, attendanceId, date, checkInTime, workMode, lateMinutes |
| attendance.checked-out | `AttendanceCheckedOut` | employeeId, attendanceId, date, checkOutTime, workedMinutes, overtimeMinutes, earlyDepartureMinutes |
| attendance.corrected | `AttendanceCorrected` | employeeId, attendanceId, date, correctedBy, reason |
| payroll.processed | `PayrollProcessed` + `PayrollLine` | runId, month, employeeCount, totalGross, totalNet, lines[employeeId, departmentId, gross, deductions, net] |
| payslip.generated | `PayslipGenerated` | employeeId, payslipId, month, filePath, fileName |
| tax.declaration.submitted | `TaxDeclarationSubmitted` | employeeId, declarationId, financialYear, regime, totalDeclared |
| tax.declaration.reviewed | `TaxDeclarationReviewed` | employeeId, declarationId, financialYear, decision, reviewerId, comment |
| performance.review.submitted | `PerformanceReviewSubmitted` | employeeId, reviewId, cycleId, stage, managerId, rating |
| performance.review.approved | `PerformanceReviewApproved` | employeeId, reviewId, cycleId, finalRating |
| timesheet.submitted / approved | `TimesheetSubmitted` / `TimesheetApproved` | employeeId, timesheetId, weekStart, totalHours, billableHours, approverId |
| resignation.submitted | `ResignationSubmitted` | employeeId, resignationId, managerId, requestedLastWorkingDay, noticePeriodDays, reason |
| employee.exited | `EmployeeExited` | employeeId, resignationId, lastWorkingDay, exitType |
| settlement.processed | `SettlementProcessed` | employeeId, resignationId, netPayable, paymentReference |
| holiday.changed | `HolidayChanged` | employeeId (null), holidayId, name, date, action, locationId |
| project.allocation.changed | `ProjectAllocationChanged` | employeeId, projectId, projectName, allocationPercent, action, startDate, endDate |
| notification.requested | `NotificationRequested` | employeeId, recipientEmail, type, templateCode, params, channels, referenceType, referenceId, dedupKey |
